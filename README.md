# 📡 VlessForU – Автоматическая подписка с рабочими VLESS/VMESS/Trojan

Этот репозиторий автоматически собирает и тестирует прокси-конфиги из публичных источников, оставляя только **реально работающие** серверы с задержкой менее 700 мс.  
Обновление происходит **каждый час** – вы всегда получаете свежий список активных узлов.

## 🚀 Готовая подписка для вашего клиента

Подписка доступна на сайте:
https://sub.vlessfo.ru

## Откуда берутся сервера?

Я тупо стягиваю их из открытых пабликов (спасибо igareck, Hidashimora и другим ребятам). Ссылки на источники есть в lol файле, если чё.

Каждый конфиг проходит проверку через реальный xray:
- Стучит на 3 сайта (1.1.1.1, Гугл, самсунг)
- Если хотя бы 2 ответили и пинг не выше 700 мс — сервер попадает в подписку

Дубликаты по IP/портам тоже вырезаются, чтобы не раздувать список.

## Почему оно работает на телефоне?

Потому что я сделал подписку без щифра. И прокинул `allowInsecure: true` где надо.

## Что не так?

Автоматика не дает 100% гарантии. Бывает:
- Сервер падает между проверками (но подожди 20 минуток — он уползет)
- Твой оператор блокирует конкретный IP или SNI
- Клиент на телефоне тупит с Reality (попробуй поменять fingerprint в настройках клиента)

Ничего идеального в этом мире нет, но так точно лучше, чем руками по 200 конфигов тыкать.
