## 📖 О проекте

**VlessForU** — это продвинутое решение для автоматического сбора, фильтрации, тестирования скорости и маршрутизации VPN-конфигураций. Проект включает в себя умный парсер-тестер на Python (`1.py`) и элегантный одностраничный веб-интерфейс (`index.html`) для удобного импорта конфигураций в клиенты **Happ** и **Incy**.

Система автоматически проверяет публичные узлы на доступность, измеряет скорость отклика (через локальное поднятие Xray ядра) и формирует готовый файл подписки с кастомным цветовым профилем и правилами маршрутизации, автоматически публикуя его на GitHub Pages.

---

## ✨ Ключевые возможности

* 🛡️ **Продвинутая фильтрация:** Поддержка белых и черных списков доменов, CIDR-диапазонов и IP-адресов. Автоматическая блокировка нежелательных путей (WS Patch Blocklist).
* ⚡ **Глубокое тестирование (Xray Core):** Проверка реальной скорости скачивания и TCP-пинга через локальное проксирование.
* 📱 **Интеграция с Happ / Incy:** Готовый лендинг с поддержкой Deep Links (`happ://add/...` и `incy://add/...`) для мгновенного добавления подписки в один клик.
* 🌐 **Поддержка современных протоколов:** Парсинг VLESS, VMess и Trojan, полная поддержка XHTTP и Reality.
* 📡 **Умный Multi-Operator LTE:** Раздельное тестирование и приоритизация конфигов для мобильных операторов со специальными таймаутами.
* 🎨 **Кастомный дизайн подписки:** Автоматическое внедрение цветового профиля (Base64), фейкового HWID и настроек маршрутизации (FakeDNS, кастомные правила) прямо в выдаваемый файл.
* 🤖 **Авто-VPN для загрузки баз:** Скрипт умеет поднимать локальный fallback-прокси из свежих рабочих конфигов, если основные источники недоступны.

## ⚙️ Установка и запуск

### Требования
Для работы скрипта требуется **Python 3.9+** и установленное в системе ядро **Xray**.
> 💡 *Подсказка: Xray можно легко установить через ваш пакетный менеджер (например, `yay -S xray` для Arch Linux или `apk add xray` для Alpine Linux).*

### Настройка окружения
Скрипт управляется через переменные окружения. Задайте их перед запуском:

```bash
export GITHUB_TOKEN="ваш_токен_github"  # Обязательно для пуша подписки
export FETCH_WORKERS=6                 # Потоки загрузки источников
export PING_WORKERS=30                 # Потоки для TCP-пинга
export MAX_WORKERS=7                   # Потоки для Xray-теста
export UPDATE_INTERVAL=7200            # Интервал полного обновления (сек)
```

### Запуск тестера
```bash
pip install requests urllib3
python3 1.py
```
